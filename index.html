🏃 MileRunner

A research platform that trains populations of AI agents to discover the fastest possible one-mile run for an average human body — under realistic muscles, tendons, fatigue and energy systems. No technique is hard-coded; it's all discovered.

Heads up — this is a program you run, not a website.
MileRunner runs heavy physics (MuJoCo) and neural-network training (PyTorch) on your own computer or a server. A hosting service like Vercel can only show this info page — it can't execute the training or the live dashboard. Follow the steps below to actually run it.

▶ Run it in 3 steps

  1. Clone the repo and install dependencies (needs Python 3.9+):
git clone https://github.com/granthicks14/claudeDRLsimulation.git
cd claudeDRLsimulation
pip install -r requirements.txt
  1. Start the autonomous training (auto-starts, runs until you press Ctrl-C):
python scripts/run.py                 # or:  --config smoke   for a fast 2-min demo
  1. In a second terminal, open the live dashboard:
python scripts/dashboard.py
# then open  http://127.0.0.1:8050  in your browser

Pause anytime with Ctrl-C and re-run to resume — progress, checkpoints and the best models are saved automatically. Also try: python scripts/evaluate.py python scripts/analyze.py python scripts/benchmark.py --all

Under the hood

🦵 Real biomechanics

3D MuJoCo humanoid (exact 77 kg, clinical joint limits) with VO₂max, heart rate, lactate, the critical-power/W′ anaerobic reserve, glycogen, tendon economy, thermoregulation and per-muscle fatigue.

🧠 It discovers, we don't

Stride, cadence, pacing, arm swing and breathing all emerge from RL under physical constraints. No strategy is coded.

🧬 Population-based training

Thousands of agents evolve: keep the best 10%, mutate & breed offspring, warm-start from elites — so experience compounds.

📈 Live dashboard

Speed, cadence, heart-rate, oxygen, energy & lactate curves, a muscle-fatigue heat-map, and an animated 3D replay of the best runner.

💾 Never lose progress

An SQLite database records every experiment and preserves the best models; pause and resume indefinitely.

⚡ Laptop → cluster

Scales by config from a CPU laptop to multi-GPU servers; CUDA is used automatically when available.
